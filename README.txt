PHYSICS LAB X — iPhone PWA

This build is a Progressive Web App designed for Safari on iPhone.

IMPORTANT: iPhone requires the app to be served from HTTPS for the Service Worker/offline installation to work reliably. Opening index.html directly from Files may show the page but will not provide full PWA installation/offline behavior.

Recommended iPhone setup:
1. Put this folder on an HTTPS static host.
2. Open the site's index.html in Safari.
3. Tap Share.
4. Tap Add to Home Screen.
5. Launch Physics Lab X from the new Home Screen icon.

Included experiments:
- Projectile Motion
- Simple Pendulum
- Mass–Spring Oscillator
- Ohm's Law Circuit
- Electromagnet

The app is self-contained and has no external libraries.
